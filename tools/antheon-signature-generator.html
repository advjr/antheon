How to add this to your email client
  1. Gmail: Settings → See all settings → General → Signature. Create or select a signature, click inside the box, then paste (Cmd/Ctrl+V).
  2. Outlook (web/new): Settings → Mail → Compose and reply → Signature box → paste.
  3. Outlook (desktop): File → Options → Mail → Signatures → paste into the editor. If formatting looks off, use "Copy HTML source" above and paste it via Outlook's signature editor in HTML view, or a Word document first, then copy again into Outlook.
  4. Apple Mail: Mail → Settings → Signatures → paste into the signature field.
